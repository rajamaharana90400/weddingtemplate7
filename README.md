# Wedding Invitation Project

This is an interactive wedding invitation card website built with React, Vite, Tailwind CSS, Three.js, Framer Motion, and GSAP.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open your browser at [http://localhost:3000](http://localhost:3000)
